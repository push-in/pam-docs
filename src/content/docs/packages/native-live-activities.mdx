## Start here

Every PAM Native product runs on the PAM runtime. Install and verify PAM first,
create a Native application, and add this package through PAM Composer:

```bash
curl -fsSL https://push-in.github.io/pam/install.sh | sh
pam doctor
pam init my-app --template native
cd my-app
pam composer require pushinbr/pam-native-live-activities
pam doctor
pam native dev
```

```php
$activities = new LiveActivities();
$content = new LiveActivityContent(
    'Order on the way',
    'Preparing',
    0.15,
    'myapp://orders/42',
);

$activities->start('order-42', $content, function (?string $id, ?string $error) use ($activities): void {
    if ($id !== null) {
        $activities->update($id, new LiveActivityContent('Order on the way', 'Courier assigned', 0.45));
    }
}, pushEnabled: true);
```

`LiveActivities` starts, updates, lists, and ends activities;
`LiveActivityContent` bounds title, status, progress, and deep link. Persist the
returned identifier and reconcile through `active()` after restart.

iOS 16.2+ remote updates require authenticated APNs token delivery. Android
13+ requires notification permission. Update only when displayed information
materially changes; Live Activities are not a high-frequency data channel.

`LiveActivitiesPluginProvider` registers the iOS extension contract.
