## Installation rule

Use PAM aliases for official application capabilities:

```bash
pam packages
pam add observability
pam add mobile-ui
pam doctor
```

`pam composer require` remains correct for normal server/framework packages
such as `pushinbr/pam-api` and `pushinbr/pam-laravel`. Distribution mirrors are
not separate installation choices.
