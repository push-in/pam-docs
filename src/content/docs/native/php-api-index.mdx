This index maps the Composer-autoloaded surface in `packages/native/src`. Use
the focused guides for behavior and examples; use this page to discover the
exact type responsible for a capability.

```bash
pam composer require pushinbr/pam-native
pam doctor
```

## Internal namespace

Types under `Pam\Native\Internal` are autoloadable because of PSR-4, but they
are implementation details for compilation, encoding, reconciliation and
runtime supervision. Do not couple application code to `Runtime`,
`RuntimeSupervisor`, `Wire`, `TreeEncoder`, `TemplateCompiler`,
`TemplateRenderer`, `PamPhpCompiler`, `PamPhpComponent`, `PamPhpRegistry`,
`PamPhpPreloader`, `EncodedNode`, `EncodedSubtree`, `CompiledTemplateNode`,
`CompiledComponentView`, `DependencyTracker`, `ComponentLifecycle`,
`ScopedStyleCompiler`, `TemplateExpression`, or `SubtreeCacheCandidate`.

Their presence in Composer autoloading is not a stability promise. Public
application contracts live outside `Internal` and follow the Native protocol
and compatibility policy.
