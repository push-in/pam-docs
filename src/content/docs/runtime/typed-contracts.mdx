---
title: Typed contract generation
description: Generate deterministic JSON Schema, OpenAPI, mobile, forms, MCP, TypeScript, Kotlin, migration, and Markdown contracts from attributed PHP.
---

PAM compiles attributed PHP DTOs and integer-backed enums into one portable
contract set. PHP remains the source of truth; generated files are deterministic
and must not be edited by hand.

## Define a contract

```php
use Pam\Contract\Data;
use Pam\Contract\Field;

#[Data(description: 'Lifecycle of an order.')]
enum OrderStatus: int
{
    case Pending = 1;
    case Paid = 2;
    case Shipped = 3;
}

#[Data(description: 'Command accepted by the order boundary.')]
final readonly class CreateOrder
{
    /** @param list<string> $tags */
    public function __construct(
        #[Field(format: 'uuid')]
        public string $id,
        public OrderStatus $status,
        #[Field(itemType: 'string')]
        public array $tags,
        #[Field(minimum: 1, maximum: 1000)]
        public int $quantity,
    ) {}
}
```

`#[Data]` accepts an optional generated name and description. Public non-static
properties become fields. Supported values are scalar PHP types, arrays with
explicit `itemType`, other attributed DTOs, and attributed enums. Nullable PHP
types become nullable schema/client types.

Enums must be integer-backed and sequential from `1`, keeping persistence,
wire formats, TypeScript, and Kotlin aligned.

## Generate every target

```bash
pam contracts bootstrap/contracts.php --output generated/contracts
```

The output directory must be empty; PAM refuses to overwrite populated output.

| Artifact | Consumer |
| --- | --- |
| `contracts.schema.json` | JSON Schema 2020-12 validation |
| `openapi.components.json` | OpenAPI 3.1 components |
| `contracts.mobile.json` | PAM Native and mobile runtimes |
| `contracts.forms.json` | Form/control generation |
| `contracts.mcp.json` | MCP resources and schemas |
| `contracts.migrations.json` | Advisory database column plan |
| `contracts.ts` | TypeScript interfaces and integer enums |
| `Contracts.kt` | Kotlin data classes and integer enums |
| `CONTRACTS.md` | Human-readable reference |

Migration output is advisory. Review names, indexes, relationships, and
destructive changes before creating a database migration.

## CI drift gate

```bash
generated_dir="$(mktemp -d)"
pam contracts bootstrap/contracts.php --output "$generated_dir"
diff -ru generated/contracts "$generated_dir"
```

A diff means source and distributed artifacts disagree. Regenerate
intentionally, review all targets, and commit them together. Schema version `1`
is validated at PHP and Rust boundaries; duplicate names, unsupported kinds,
malformed fields, and non-sequential enums fail instead of producing partial
output.
